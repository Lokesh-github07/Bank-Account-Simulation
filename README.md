# 💳 Bank Account Simulation – Internship Task 5

A simple **Java console application** that simulates basic bank account operations.  
It allows creating accounts, depositing money, withdrawing funds, and checking balances.

## ▶️ Run Instructions
1. Clone the repo: `git clone https://github.com/Lokesh-github07/Bank-Account-Simulation.git`
2. Compile: `javac src/*.java`
3. Execute: `java BankApp`

## 📂 Structure
- `Account.java` → model class representing a bank account with fields and methods for transactions  
- `BankApp.java` → main driver class providing a menu‑driven interface for account operations
